# 7-Zip — быстрый архиватор 📦

Бесплатный архиватор с высокой степенью сжатия. Поддерживает форматы 7z, ZIP, RAR, TAR, GZIP, XZ и другие.

## Возможности

- 🗜️ Сжатие в формате 7z — на 10–30% лучше, чем ZIP
- 🔓 Распаковка RAR без платного WinRAR
- 🖱️ Интеграция с контекстным меню проводника
- 🔒 Шифрование AES-256 для архивов
- 🧩 Поддержка командной строки (7z.exe)

## Установка

1. Скачайте установщик из раздела [Releases](../../releases)
2. Запустите `7z.exe` и следуйте инструкциям мастера установки
3. Готово — архиватор появится в контекстном меню правой кнопкой мыши
